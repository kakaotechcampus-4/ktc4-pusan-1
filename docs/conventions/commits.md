# 커밋 메시지

기준 2026-11-10 · `develop` `c78c543`

## 형식

```
<타입>(<scope>): 한국어 요약
```

예시 — 지금 `develop` 에 실제로 들어있는 것들입니다.

```
feat(common): 6페이지 설명 문단을 「지키는 쪽」 장면으로 바꾸고, 띠 이름을 키운다
fix(common): 발표자료에서 표지와 데모 말고는 아무것도 안 보이던 것을 고친다
fix(fe): 화면낭독기가 아이콘 글자를 읽지 않게 한다
test(fe): 로컬 LiveKit 통화에서 자막 접기 초점 화면을 촬영한다
```

## 타입

| 타입 | 쓸 때 |
| --- | --- |
| `feat` | 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서만 변경 |
| `test` | 테스트만 추가·수정 |
| `refactor` | 동작 그대로 구조만 변경 |
| `perf` | 성능 개선 |
| `style` | 포맷·공백·세미콜론 등 |
| `chore` | 빌드·설정·의존성 |
| `ci` | 워크플로 변경 |

## scope

디렉터리를 그대로 씁니다 — `fe`, `be`, `ai`, `infra`, 그리고 두 개 이상 파트에 걸치면 `common`.

scope 를 디렉터리에 묶어 두는 이유는 CI 가 경로로 갈려 있어서입니다. `fix(fe)` 커밋이 `ai/` 를 건드리고 있으면 그 자체로 신호입니다.

## 요약문

- 한국어로, 마침표 없이 씁니다.
- 「무엇을 했는지」를 적습니다. 「왜」는 본문이나 PR 본문에 적습니다.
- 50자 안쪽으로 맞춥니다. 지금 히스토리에는 더 긴 것도 있는데, 앞으로 올리는 것부터 맞춥니다.

## 지금 상태

최근 60개(머지 커밋 제외) 중 **12개에 타입 접두어가 아예 없습니다.** 발표자료 작업에서 한국어 문장만 적힌 커밋이 몰려 나왔습니다. 나머지 48개는 타입 접두어가 있고(그중 2개는 scope 가 없습니다), 분포는 `fix(fe)` 18 · `chore(common)` 8 · `test(fe)` 6 · `fix(ai)` 4 · `feat(fe)` 2 순입니다.

소급해서 고치지 않습니다. 히스토리를 다시 쓰면 열린 PR 들이 전부 깨집니다. **앞으로 올리는 커밋부터** 맞춥니다.

## 검사하지 않습니다

커밋 메시지를 막는 훅이나 CI 는 없습니다. `convention-check.yml` 은 `develop → main` PR 에서만 돌고, 규칙 본문도 외부 저장소에서 가져오는 것이라 우리 규칙이 아닙니다. 이 문서는 리뷰에서 서로 짚어 주는 기준입니다.
