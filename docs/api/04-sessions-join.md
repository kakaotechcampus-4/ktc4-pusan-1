## FE 참고

### 확인 필요 (FE 최우선)

1. **`role` 이 응답에 포함되나요?** issue #9 코멘트에서 "실어 보내는 게 맞다" 고 하셨는데 명세 표에는 없습니다.
   **이게 없으면 FE 는 면접관 화면과 지원자 화면을 구분할 수 없습니다.**
2. **전사·추천 질문 WebSocket URL 이 여기 실려 오나요?** 명세 어디에도 이 경로가 없습니다 (AI #7).
   AI 파이프라인이 미완이면 `null` 로 내려주세요 — 전사가 없어도 통화는 진행되게 처리해뒀습니다.
3. **에러 코드 문자열**이 필요합니다. FE 는 아래 4가지 화면을 이미 분기해 뒀습니다.
   현재는 HTTP status 로 추정하고 있어, 본문 `error.code` 가 확정되면 매핑 한 곳만 고치면 됩니다.

| 화면 | 문구 | 추정 status | 서버 code |
| --- | --- | --- | --- |
| 없는 세션 | 유효하지 않은 링크입니다 | 404 | ? |
| 권한 없음 | 입장할 권한이 없습니다 | 403 | ? |
| 종료됨 | 이미 종료된 면접입니다 | 410 | ? |
| 정원 초과 | 이미 두 명이 입장해 있습니다 | 409 | ? |

4. **join 을 두 번 부르면 같은 사람으로 인식되나요?** 새로고침·재접속·토큰 만료가 모두 재호출로 이어집니다.
   같은 사람으로 안 보면 정원 2명을 혼자 채우게 됩니다.
5. **정원 판정 시점** — `join → 기기 점검 → 접속` 순서라 점검하는 30초~2분 사이에 정원이 찰 수 있습니다.
   join 이 자리를 예약하나요? 예약한다면 이탈 시 언제 풀리나요?
6. **토큰 TTL** 은 얼마인가요?
