# KWCAG 2.2 접근성 점검 반영 (2026-10 보고서)

카카오 테크 캠퍼스 「부산대 1팀(IRYA) 접근성 상세 이슈 보고서」(검수 2026-10-22 ~ 10-30, Chrome 155)의
지적 사항과, 보고서가 함께 공유한 나머지 KWCAG 2.2 지침을 코드에 맞춰 점검한 결과입니다.

- 검수 버전은 10월 27일 빌드입니다. 그 뒤로 지원자 목록이 바뀌어 일부 지적은 위치가 달라졌습니다(아래 표의 「현재 코드」).
- 수정은 FE에만 있습니다. BE 계약은 바꾸지 않습니다.

## 1. 보고된 이슈

| # | 보고 내용 | 지침 | 현재 코드에서 찾은 원인 | 수정 | 파일 |
|---|---|---|---|---|---|
| 1 | 홈 · 업무 화면에 반복 영역 건너뛰기 링크 없음 | 반복 영역 건너뛰기 | 사이드바 · 위 막대 다음에 본문이 오는데 건너뛸 수단이 없었다 | 화면 맨 앞에 「본문 바로가기」. 평소 숨기고 Tab 으로 들어오면 보인다. 누르면 주소를 바꾸지 않고 `main#main-content` 에 초점 | `components/layout/SkipLink.tsx`, `AppShell.tsx`, `LegalLayout.tsx`, `pages/LandingPage.tsx` |

## 2. 보고되지 않은 지침 점검

코드에서 위반이 확인된 것만 고쳤습니다.

| 지침 | 결과 | 조치 |
|---|---|---|
| 적절한 대체 텍스트 | 통과 | 정보 이미지는 설명 alt, 장식 이미지는 `alt=""`, 아이콘은 `aria-hidden` |
| 텍스트 명도 대비 | **위반 → 수정** | 면접 화면 유리판이 흰 벽 · 밝은 조명 영상 위에서 흰 글씨가 묻혔다. 읽는 패널에 어두운 유리를 깔아 흰 바탕에서도 4.5:1 이상을 지키고 글자 그림자는 뺀다 (꼬리질문 스타일 PR) |
| 키보드 사용 보장 | 일부 보완 | 자막 기록 영역이 키보드 초점을 받아 화살표로 올려 읽을 수 있다 |
| 정지 기능 | **위반 → 수정** | 실시간 자막은 위로 올리면 자동 스크롤을 멈추고 「최신 자막으로」를 보인다. 꼬리질문 큐에는 「일시정지」를 둔다 (꼬리질문 큐 PR) |
| 제목 제공 | **위반 → 수정** | 모든 화면이 같은 `<title>` 이었다. 경로별로 「지원자 관리 \| IRYA」처럼 바꾼다 (`lib/pageTitle.ts`) |
| 표의 구성 | **보완** | 지원자 표에 `caption` 과 열 제목 `scope="col"` |
| 레이블과 네임 | **보완** | 꼬리질문 「지우기」 버튼 이름을 「지우기: 질문」으로 보이는 글자가 앞에 오게 바꾼다 (꼬리질문 큐 PR) |
| 색에 무관한 인식 | 통과 | 화자 · 검토 상태 · 고정은 색과 함께 글자나 아이콘으로 구분한다 |
| 기본 언어 표시 | 통과 | `index.html` 에 `lang="ko"` |
| 사용자 요구에 따른 실행 | 통과 | 콤보박스는 목록 필터만 바꾸고 화면 이동 · 새 창은 없다 |
| 자동 재생 금지 · 깜빡임 | 통과 | 소리는 면접 통화뿐이고 사용자가 입장해야 시작한다. 깜빡임은 움직임 줄이기에서 꺼진다 |
| 접근 가능한 인증 | 통과 | 카카오 소셜 로그인 |
| 마크업 오류 방지 | 통과 | 새로 넣은 id(`main-content`, `review-tab-*`, `candidate-*`)는 화면마다 하나다 |

## 3. 적용하지 않은 것

- 면접 화면(통화)에는 본문 바로가기를 두지 않았습니다. 여러 화면에 반복되는 메뉴가 없고, 상단 막대에 버튼이 하나뿐입니다.
- 리포트 화면의 제목은 `h2` 입니다. 같은 컴포넌트를 관리 화면 안에서도 쓰고 있어 바꾸지 않았습니다.
- 자동 검사 도구(axe 등)는 붙이지 않았습니다. 로직 테스트와 브라우저 접근성 트리로 확인했습니다.

## 4. 확인 방법

- `npm test`, `npm run lint`, `npm run typecheck`, `npm run format:check`, `npm run build`
- 브라우저: Tab 첫 초점이 「본문 바로가기」인지, Enter 뒤 `main` 에 초점이 가고 주소가 그대로인지 확인했습니다.
  지원자 탭에서 화살표로 선택 · 걸러짐 · `tabIndex` 이동을 확인했습니다. 접근성 트리의 label · caption · scope 를 확인했습니다.
  실제 Tab 키로 자막 접기 버튼의 네 변 초점 테두리를 확인했습니다.
