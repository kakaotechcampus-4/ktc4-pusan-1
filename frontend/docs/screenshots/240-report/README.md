# F10 화면 검증 — 2026-10-31

현재 리포트 컴포넌트를 실제 로컬 API에 연결해 다시 촬영했다. 원래 사이트의 공통 메모·시각 칩·검토 버튼 톤을 유지했다.

- 종류별 아이콘+글자와 MISSING 카드 아이콘을 추가했다. 원문 인용·시각 null 처리와 미다룬 항목의 후속 질문은 유지한다.
- 항목 분석 실패(FAILED)와 실제 빈 목록(EMPTY)을 구분한다. 요약만 실패했지만 항목이 유효한 경우를 잘못 막지 않는다. 새 회귀 검사는 수정 전 실패, 수정 후 통과했다.
- 실제 검토 완료→생성→PROCESSING→REPORT 폴러→READY 및 메모 일치를 확인했다. 영상·STT/질문/사전 가공/검토는 테스트 대역이며 리포트는 추출형 생성기다.
- 기존 리포트 사진3개를 새 촬영본으로 교체하고 분석 실패 화면1개를 추가했다.
